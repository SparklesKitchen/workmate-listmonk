Designing e-mail templates

A template is the reusable frame around your campaign content: header, colours, footer. When you send a campaign, your message is placed inside the template.

Visual templates (recommended)

Choose Campaign / Visual when creating a template and design it by dragging blocks: text, images, buttons, dividers. No code needed. Save it, then pick it when you create a campaign.

HTML templates

Choose Campaign / HTML if you prefer writing your own HTML. One rule: the template must contain this placeholder exactly once, where the campaign content should appear:

{{ template "content" . }}

Personalising your e-mails

You can greet each subscriber by name and use their details anywhere in a template or campaign:

CodeWhat it prints
{{ .Subscriber.Name }}The subscriber's full name
{{ .Subscriber.FirstName }}First name only
{{ .Subscriber.Email }}Their e-mail address
{{ UnsubscribeURL }}The unsubscribe link (required in every campaign)
